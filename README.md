A booking system for dental clinics built with PHP and Bootstrap.

Denture is a web-based appointment booking system created as a project in 2024. It helps dental clinics manage appointments efficiently while giving patients a simple and accessible booking experience.



## 🎯 Project Purpose
This project was developed for educational and project-based purposes. It demonstrates the use of PHP, Bootstrap, and database integration using XAMPP in a real-world web application.



## 🚀 Features
- Online appointment booking
- Dental clinic scheduling system
- Responsive UI using Bootstrap
- Local deployment with XAMPP
- Easy to customize and extend


## 🛠️ Built With
- **PHP**
- **Bootstrap**
- **HTML / CSS**
- **XAMPP (Apache & MySQL)**


## 📦 Requirements
- XAMPP (Apache & MySQL)
- PHP 7.4 or higher
- Modern web browser
